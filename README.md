# 🤖 Crypto Trend Trading Bot (OKX / Bybit)

Профессиональный алгоритмический торговый робот для торговли криптовалютой по тренду (**BTC / ETH / SOL**) на **15-минутных свечах** в безопасном режиме **Paper Trading** (демо-симуляция на реальных рыночных данных).

---

## 🎯 Стратегия и Математика риска

* **Инструменты:** Топ-3 высоколиквидных актива — `BTC-USDT`, `ETH-USDT`, `SOL-USDT`.
* **Таймфрейм:** `15m` (15-минутные свечи отсекают 90% внутриминутного шума и дают 1–3 надежных сигнала в сутки).
* **Логика входа:**
  * **Тренд:** Быстрая EMA (10) выше Медленной EMA (25).
  * **Пробой волатильности (Donchian Breakout):** Закрытие свечи выше 20-периодного максимума (для лонга) или ниже 20-периодного минимума (для шорта).
  * **Вход строго на закрытой свече:** Исключает ложные срабатывания на внутрисвечном фитиле.
* **Мани-менеджмент:**
  * 🛡 **Стоп-лосс:** строго `-1.5%` (при $15 позиции риск всего `$0.22`).
  * 🎯 **Тейк-профит:** `+3.5%` (прибыль `$0.52`).
  * **Соотношение прибыли к риску:** `1 : 2.3` (математическое преимущество даже при винрейте 40%).
  * **Максимум позиций:** не более 3 одновременно (по одной на каждую пару).

## 📱 Управление через Telegram

* `/status` или `/balance` — актуальный баланс, свободные деньги, открытый капитал и винрейт.
* `/trades` — живой список открытых позиций с ценой входа, текущей котировкой и плавающим PnL.
* `/history` — список последних закрытых сделок с зафиксированной прибылью.
* `/help` — справка по командам.
