# 🏆 Crypto Algorithmic Tournament Bot

Автономный турнир 3 независимых алгоритмических стратегий для криптовалютного рынка (**BTC / ETH / SOL**) в 100% безопасном режиме **Paper Trading** (симуляция на реальных рыночных стаканах и котировках OKX).

Каждой стратегии выделен изолированный бюджет **$100.00**.

---

## ⚔️ Участники Турнира

1. ⚡ **Trend Follower (Donchian Breakout + EMA):**
   * Таймфрейм: 15m
   * Пробой 20-периодного диапазона Donchian на подтвержденной свече
   * Фильтр тренда: EMA 10 > EMA 25
   * Стоп-лосс: -1.5%, Тейк-профит: +3.5% (R:R = 1 : 2.33)

2. 🕸️ **Spot Grid (Сетка уровней):**
   * Сбор спреда и микро-колебаний во флэте
   * Шаг сетки: 1.0%, размер ордера: $10
   * Тейк-профит на шаг: +1.0%

3. 🌊 **Mean Reversion (RSI + Bollinger Bands):**
   * Ловля отскоков от экстремальных уровней перекупленности / перепроданности
   * RSI (14) < 30 / > 70 + выход за 2.0σ полосы Боллинджера
   * Стоп-лосс: -2.0%, Тейк-профит: +2.5%
