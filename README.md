# 🤖 Dual Trading Bot (Polymarket + Crypto)

Гибридный торговый робот для параллельной работы на рынках предсказаний (**Polymarket**) и криптовалютных биржах (**OKX / Bybit**) в безопасном режиме **Paper Trading** (демо-симуляция на реальных рыночных данных).

---

## 🎯 Что умеет бот («Два в одном»)

1. **Модуль Polymarket (Рынки предсказаний)**
   - Подключается напрямую к официальному API Polymarket.
   - Сканирует активные рынки в реальном времени.
   - Находит:
     - **NegRisk Dutch Book:** математические ошибки в сумме вероятностей ($\sum P_i < 0.98$).
     - **Spread Harvester:** широкие спреды между заявками на покупку и продажу.
     - **Favorite Harvester:** недооцененные фавориты с высокой вероятностью успеха перед резолюцией.
   - Каждая сделка содержит **прямую кликабельную ссылку на событие на Polymarket** для моментальной ручной проверки.

2. **Модуль Crypto (OKX / Bybit)**
   - Получает живые минутные свечи по топ-активам: `BTC-USDT`, `ETH-USDT`, `SOL-USDT`.
   - Рассчитывает трендовые каналы (Donchian Volatility Breakout + EMA).
   - Автоматически управляет сделками:
     - 🛡 **Жесткий стоп-лосс:** риск ровно 1.5% на сделку.
     - 🎯 **Тейк-профит:** соотношение прибыли к риску > 1:2 (+3.5%).

3. **Общий центр управления**
   - Единая сводная таблица баланса и PnL прямо в терминале.
   - Оповещения в Telegram в реальном времени (открытие, закрытие, фиксация прибыли).
   - Сохранение состояния портфеля в `portfolio_state.json` (баланс не сбрасывается при перезапуске).

## 🚀 Вариант 1: Запуск на вашем Маке (за 30 секунд)

```bash
# 1. Перейдите в папку проекта
cd /Users/arsenykozlov/.gemini/antigravity/scratch/dual_trading_bot

# 2. Активируйте виртуальное окружение
source .venv/bin/activate

# 3. Запустите бота

```

Чтобы остановить бота, нажмите `Ctrl + C`. Состояние портфеля будет автоматически сохранено.

## ☁️ Вариант 2: Запуск бесплатно на GitHub (Codespaces)

GitHub бесплатно предоставляет **60 часов в месяц** виртуального сервера на Linux (Ubuntu) с европейским/американским IP-адресом.

1. **Создайте репозиторий на GitHub:**
   ```bash
   git init
   git add .
   git commit -m "feat: initial dual trading bot"
   # привяжите к вашему репозиторию на github:
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЮЗЕРНЕЙМ>/dual-trading-bot.git
   git push -u origin main
   ```
2. **Запустите в один клик:**
   - Откройте ваш репозиторий на сайте [GitHub](https://github.com).
   - Нажмите зеленую кнопку **`< > Code`** ➔ вкладка **`Codespaces`** ➔ **`Create codespace on main`**.
   - GitHub откроет облачный VS Code в браузере, автоматически установит все зависимости через `.devcontainer/devcontainer.json`.
   - В терминале браузера просто введите:
     ```bash
     python3 main.py
     ```
   - Бот будет работать на облачном сервере в Европе, а отчеты слать вам в Telegram!

## 📱 Как подключить уведомления в Telegram (за 1 минуту)

1. Откройте в Telegram бота **`@BotFather`** и отправьте команду `/newbot`. Задайте имя (например, `MyAstraTraderBot`) и скопируйте полученный токен.
2. Откройте бота **`@userinfobot`** в Telegram, чтобы узнать свой цифровой `Id` (например, `123456789`).
3. Откройте файл `.env` в папке проекта и вставьте:
   ```env
   TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
   TELEGRAM_CHAT_ID="ВАШ_ID"
   ```
4. Перезапустите бота — он сразу пришлет вам приветственное сообщение о запуске!
